ひな壇プランナー プライバシーポリシー

1. 取得する情報

本アプリは、お客様の個人情報を取得・収集しません。

2. 端末内に保存する情報

前回の入力値(撮影人数、足の段数、セット数、板の幅、1人あたりの幅)を、お客様の端末内にのみ保存します。保存した値は外部に送信しません。アプリを削除すると、この値も削除されます。

3. 外部への送信

本アプリは、入力値や利用状況をサーバーに送信しません。広告配信、アクセス解析、第三者への情報提供も行いません。

4. 外部リンク

アプリのメニューからこのページを開くとき、端末の標準ブラウザが起動します。

5. 変更

内容を変更する場合は、このページで告知します。

6. お問い合わせ

GitHub の Issues からご連絡ください。
