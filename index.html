ひな壇プランナー プライバシーポリシー

1. 基本方針

本アプリは、氏名やメールアドレスなど、お客様を直接特定する情報を取得しません。撮影人数などの入力値は、端末の外へ送信しません(下の広告や購入のサービスにも渡しません)。

ただし、広告の表示(Android・iOS)と、広告を非表示にする購入(iOS のみ)のために、下の外部サービスが情報を扱います。

2. 端末内に保存する情報

次の情報を、お客様の端末内に保存します。アプリを削除すると、これらも削除されます。

  • 前回の入力値(撮影人数、足の段数、セット数、板の幅、1人あたりの幅)。外部に送信しません。
  • 広告を非表示にする購入をしたかどうか。
  • 広告に関する同意の状態(広告のサービスが保存します)。

3. 広告(Google AdMob)

本アプリは、Google LLC が提供する AdMob で広告を表示します。広告の配信・効果の測定・不正の防止のため、AdMob の仕組みが次の情報を自動で収集し、Google に送信します。通信は暗号化されます。

  • IP アドレス(おおよその地域の推定に使われます)
  • 広告 ID などの端末の識別子
  • 広告の表示やタップなど、アプリでの操作
  • アプリや広告の仕組みの動作に関する診断情報

お客様に合わせた広告(パーソナライズ広告)は、同意が必要な地域では同意をいただいた場合に限り表示されます。iOS では、トラッキングを許可した場合に限り、広告 ID(IDFA)が使われます。許可しなくても、アプリの機能はすべて使えます。

設定は、次の方法で変えられます。

  • iOS: 端末の「設定」の「プライバシーとセキュリティ」→「トラッキング」
  • Android: 端末の「設定」の広告に関する項目(広告 ID のリセットや削除)
  • 同意が必要な地域では、アプリのメニューの「広告のプライバシー設定」

広告を非表示にする購入をした場合、広告を表示せず、広告の仕組みも動かしません。

Google による情報の扱いは、Google のサービスを使用するサイトやアプリから収集した情報の Google による使用をご覧ください。

4. アプリ内購入(RevenueCat。iOS のみ)

iOS 版では、広告を非表示にする購入・購入の復元・購入状態の確認のため、RevenueCat, Inc. のサービスを使います。RevenueCat には、アプリが自動で作る匿名の ID と、App Store での購入の履歴、言語と通貨の設定が送信されます。通信のため、IP アドレスも RevenueCat に届きます。氏名・メールアドレス・広告 ID は送信しません。

代金の支払いは Apple が処理します。本アプリと RevenueCat は、クレジットカードなどの支払いの情報を受け取りません。

RevenueCat による情報の扱いは、RevenueCat のプライバシーポリシーをご覧ください。

Android 版には、購入の機能はありません。

5. アクセス解析と第三者への提供

本アプリは、アクセス解析を行いません。法令に基づく場合を除き、上の広告と購入のサービス以外の第三者に、情報を提供しません。

6. 外部リンク

アプリのメニューからこのページを開くとき、端末の標準ブラウザが起動します。

7. 変更

内容を変更する場合は、このページで告知します。
